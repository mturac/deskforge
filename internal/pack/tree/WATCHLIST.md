- Family/shared-life tools that remove an app from elders or kids

- Copy / cut / add → new brand (not "X but free")
- Prefer Cursor skill / plugin / single-binary CLI as v0 surface

- GitHub trending (daily + weekly)
- Note hits in `vault/signals/` or explicit `checked-empty` in the cycle note

## Silence rule

`nothing_today` only after household + challenger + PH/GH radar + open p0 demands are checked.
