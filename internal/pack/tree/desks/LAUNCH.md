# Launch bar — Product of the Day / trending repo

This desk does not ship quiet hobbies. Promoted ideas need a credible path to:

1. **Product Hunt — Product of the Day** (or launch-day #1–#5)
2. **GitHub — trending energy** (star velocity + Show HN / social loop)

## Before build

| Gate | Bar |
| --- | --- |
| Hero | One sentence a stranger repeats |
| Demo | GIF or 30s of the magic moment |
| Install | Under 10 minutes to first value |
| Audience | Household gift **or** people who feel the incumbent’s pain |
| Differentiation | Clear vs nearest winner + copy/cut/add |
| Share loop | Someone sends it to a friend or Show HN |

## Human gate

- `build <slug>` — unlock Builder
- `hold` — park until a stronger launch story
- usable **kit** ships (agent packs / skills / init) may land earlier when the human asked for something they can run
