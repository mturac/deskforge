# PREFLIGHT — gate before human brief

Scout fills this block on every idea before status `briefed`.

```yaml
preflight:
  result: pass|fail
  window: hot|warm|cold
  surface: skill|plugin|cli|other
  incumbent: <name + proof link>
  copy_cut_add: <one line>
  occupancy: <why this is not a clone of existing OSS>
  fold_forbidden: true|false
  evidence_links: []
```

## Pass requires

1. Dated demand proof (paywall, PH rank, GH spike, or signed waitlist)
2. Honest occupancy check (do not clone star-occupied OSS)
3. First workflow ≤ 10 minutes to value
4. Kill criteria written
5. Not a silent fold into an existing slug unless proven same job

## Fail → do not brief humans

Open or update a DEMAND for the missing piece. Log reject code if you keep missing the same window.
